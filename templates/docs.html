Set up

Python 3.10 or 3.11 is recommended. From the project folder:

py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python app.py
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py

Then open http://127.0.0.1:5000.

Dataset format

Create data/metadata.csv with one row per labelled mixture. Paths may be absolute or relative to the CSV.

mixture_path,num_sources,split
audio/mix_0001.wav,2,train
audio/mix_0002.wav,3,val
audio/mix_0003.wav,4,test
  • num_sources must be a whole number from 1 to --max-sources.
  • The trainer uses the train and val splits. Keep test for the final evaluation.
  • Split the original recordings before mixing, so the same stems never appear in both train and test.

Train the model

python train.py --metadata data/metadata.csv --epochs 25 --max-sources 32

The best checkpoint by validation loss is saved to checkpoints/source_count_cnn.pt. The app finds it on the next request, so no restart is needed. Current status: {{ 'checkpoint found' if status.trained else 'no checkpoint yet' }}.

API

RouteWhat it does
GET /api/healthReports that the server is up and whether a checkpoint exists.
POST /api/predictMultipart upload in the field audio. Returns signal details and, when trained, the estimate with a per-window timeline.
curl -X POST -F "audio=@example.wav" http://127.0.0.1:5000/api/predict
Press the button to call the server.

Known limits

  • Without a trained checkpoint the app reports signal statistics only.
  • One 8-second window is analysed. Long files are centre-cropped and short files are padded.
  • Softmax confidence is not a guarantee of correctness.
  • The training clips are 8 seconds long but inference uses 2-second windows. Check accuracy on held-out data, or train on matching window lengths.
  • The app is for local development and is not hardened for public hosting.
