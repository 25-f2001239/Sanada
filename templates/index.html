    Convert to mono and resample to {{ (sr / 1000)|int }} kHz.

  2. Crop or pad

    Fit the clip to one {{ clip_s|int }}-second window.

  3. Convert

    Turn the full clip into a 64-band log-mel spectrogram.

  4. Classify

    A small CNN estimates one source count for the full clip.

Questions people ask

Does it separate the sources into files?

For 2-speaker speech mixtures, yes — the installed SepFormer model separates two speakers into WAV stems plus a residual and ZIP bundle. General non-speech separation and 3+ speaker separation are disabled unless a trained separator checkpoint is loaded.

Why does it say the model is not trained?

The app needs a checkpoint at checkpoints/source_count_clip.pt. Run python scripts/download_models.py or train with python scripts/train.py all --full. The Docs page lists the exact commands.

What happens to my audio?

Uploaded audio is processed on the server in an isolated job folder and deleted automatically after {{ job_ttl_minutes }} minutes and on server startup. Your run history stays in this browser only.

What about recordings longer than 8 seconds?

Only the middle 8 seconds are analysed, and the waveform marks which part. Shorter recordings are padded with silence.

Can I trust the confidence number?

It shows how decisive the network was, not whether it was right. Check accuracy on a held-out test set before relying on it.
