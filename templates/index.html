From file to count

  1. Load

    Convert to mono and resample to {{ (status.sample_rate / 1000)|int }} kHz.

  2. Crop or pad

    Fit the clip to one {{ status.clip_seconds|int }}-second window.

  3. Slide

    Cut 2-second windows with a 1-second hop.

  4. Classify

    A small CNN reads each log-mel spectrogram.

  5. Vote

    The most frequent window count is the answer.

Questions people ask

Does it separate the sources into files?

No. It only estimates how many sources overlap. Separation is a different model and a different project component.

Why does it say the model is not trained?

The app needs a checkpoint at checkpoints/source_count_cnn.pt. Train one from labelled mixtures with train.py. The Docs page lists the exact command.

What happens to my audio?

It is sent to the Flask server running on your computer, analysed, and the temporary file is deleted. Your history stays in this browser only.

What about recordings longer than 8 seconds?

Only the middle 8 seconds are analysed, and the waveform marks which part. Shorter recordings are padded with silence.

Can I trust the confidence number?

It shows how decisive the network was, not whether it was right. Check accuracy on a held-out test set before relying on it.
