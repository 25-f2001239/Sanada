From file to count

  1. Load

    Convert to mono and resample to {{ (sr / 1000)|int }} kHz.

  2. Crop or pad

    Fit the clip to one {{ clip_s|int }}-second window.

  3. Convert

    Turn the full clip into a 64-band log-mel spectrogram.

  4. Classify

    A small CNN estimates one source count for the full clip.

Questions people ask

Does it separate the sources into files?

For sparse mixtures, yes. When the estimated count is 8 or fewer, the separator can write one WAV per source and bundle them into a ZIP. Denser mixtures are counted only, because separating them is not reliable. If the page shows an "Untrained demo weights" banner, the stems are not real separations.

Why does it say the model is not trained?

The app needs a checkpoint at checkpoints/source_count_clip.pt. Train one from labelled mixtures with train.py. The Docs page lists the exact command.

What happens to my audio?

It is sent to the Flask server running on your computer, analysed, and the temporary file is deleted. Your history stays in this browser only.

What about recordings longer than 8 seconds?

Only the middle 8 seconds are analysed, and the waveform marks which part. Shorter recordings are padded with silence.

Can I trust the confidence number?

It shows how decisive the network was, not whether it was right. Check accuracy on a held-out test set before relying on it.
