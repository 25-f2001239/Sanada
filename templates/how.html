Quality gates & residual verification

{% if public_stats %} {% set qg = public_stats.quality_gates %} {% set sep = public_stats.separation %}

1. Near-copy correlation

Flags stems whose waveform correlation exceeds {{ qg.max_correlation_threshold }} or speaker cosine exceeds {{ qg.max_speaker_cosine_threshold }} (measured 2-spk speech pairwise corr: {{ sep.real_2spk_speech.max_pairwise_corr }}).

2. Energy conservation

Checks that stems + residual reconstruct mixture energy within ±{{ (qg.energy_relative_l2_tolerance * 100)|int }}% relative L2 tolerance (pass rate: {{ '%.0f'|format(sep.energy_conservation_pass_rate * 100) }}%).

3. Self-consistency re-tagging

Re-runs the tagger on each separated stem to verify the target sound still dominates (2-spk speech pass rate: {{ '%.0f'|format(sep.real_2spk_speech.self_consistency_pass_rate * 100) }}%; synthetic FSD: {{ '%.1f'|format(sep.self_consistency_pass_rate * 100) }}%).
